# Stickman-to-SMPLX
# Python 3.11 or newer (torch needs it). No version pins on purpose: pip takes the newest release that has a wheel for your Python and OS.
# Last checked: torch, numpy, scipy and plotly all publish Windows (win_amd64) wheels for Python 3.11 to 3.14. smplx is pure Python and only needs numpy + torch.
# If a new release ever breaks something, pin that one package, for example: pip install "scipy<2"
# torch: on Windows the PyPI wheel is the CPU build. For a GPU, install torch first with the command from https://pytorch.org/get-started/locally/ (pick your CUDA version), then run pip install -r requirements.txt. The installed GPU torch satisfies the torch line and is kept.
# Not needed: torchvision, torchaudio.
# Used by: torch + smplx (get_mesh_from_smplx.py, get_skinned_mesh_from_smplx.py), numpy (all scripts), scipy (the two fitters), plotly (visualize_joints.py, visualize_smplx.py).
# preview_compare.py, mapping_stickman_to_smplx.py and get_hybrid_pose_from_stickman.py need numpy only.
